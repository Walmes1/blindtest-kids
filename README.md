# 🎵 BlindTest Kids

Jeu de blind test musical pour enfants, dans le navigateur. Ajoute des liens YouTube, l'app joue un extrait et les enfants devinent.
A browser-based music blind-test game for kids: paste YouTube links, the app plays a clip, kids guess.

- 🆓 Gratuit, sans inscription · Free, no sign-up
- 🌐 Jouer en ligne / Play online: **https://walmes1.github.io/blindtest-kids/**
- ⬇ [Télécharger / Download](https://github.com/Walmes1/blindtest-kids/releases/latest) — dézipper, ouvrir `index.html`

> ℹ️ Les vidéos sont lues via le lecteur YouTube officiel ; YouTube peut afficher ses propres publicités. L'app elle-même ne contient aucune publicité ni pistage.
> Videos play through the official YouTube player, which may show YouTube's own ads. The app itself has no ads or tracking.
